CS Messaging Web Application

This is a simple customer support messaging application built using the MERN stack. The goal of the project is to help support agents view, prioritize, and manage customer messages efficiently.


Overview

The application displays customer messages along with their urgency level and status. Messages can be viewed under different tabs such as open and history, and each message can be expanded to see more details. The UI is designed to handle frequent updates in a clean and readable way.


Tech Stack

* Frontend: React.js
* Backend: Node.js, Express.js
* Database: MongoDB

The MERN stack was chosen to enable fast development, easy state management, and efficient handling of concurrent message requests using a single language across the stack.


Key Features

* View customer messages in a structured layout
* Urgency-based prioritization (high, medium, low)
* Separate views for open and resolved messages
* Expand and collapse messages for detailed information
* Scalable backend design for future real-time updates
